# AGENTS.md

dailycryptic.org is a free, AdSense-monetized SEO content + practice hub for puzzle
solvers. No login, accounts, paywall, or membership. Goal: grow qualified organic
traffic, page depth, and ad inventory without harming the puzzle-solving experience.

Requirement and planning docs live in [`docs/`](docs/). See [CLAUDE.md](CLAUDE.md) for the
full project index. The original cryptic content-expansion roadmap is now at
[docs/cryptic-content-requirements.md](docs/cryptic-content-requirements.md).
